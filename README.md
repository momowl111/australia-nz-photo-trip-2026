# 南半球，追光十一日

悉尼与新西兰南岛的中文摄影旅行手册，主方案为 **2026年11月16日至26日**。3人同行、8晚住宿，上海出发和返回，先澳洲后新西兰。

**打开网页：[南半球追光十一日](https://momowl111.github.io/australia-nz-photo-trip-2026/)**

## 可以做什么

- 按日期查看路线、时段、摄影建议及候选酒店，点地点可打开地图导航。
- 查看11张有作者与许可信息的真实摄影参考。
- 查看历史气候、日月时刻、风雨替代安排、无人机与行前注意事项。
- 用分享按钮复制当前日期的链接，或打印完整11日计划。

## 状态与边界

资料核查日期为2026年10月21日。所有安排均未预订。航班、房价、床型、取消条件、道路与步道开放情况应在预订及出发前复核。11月17日选项仅是顺延草案，机票、房价和日月时刻尚未按新方案复核。

地图虚线表示访问顺序，不是道路导航；坐标为规划参考，正式停车入口以现场标识为准。日出日落采用理论地平线，山体可能提前遮光。历史照片不代表本次日期一定可以见到的天气、花况或光线。

本公开仓库只包含旅行规划资料，没有护照、签证批准信、身份信息或预订凭证。

## 本地预览与更新

这是无需构建的静态网页。在本目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/`。更新 `data.json` 修改行程和来源，`app.js` / `style.css` 修改交互与样式。GitHub Pages 从 `main` 分支根目录发布。
