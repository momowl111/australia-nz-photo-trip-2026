## 本地预览与更新

这是无需构建的静态网页。在本仓库目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/`。`data.json`保存行程、预算和来源，`app.js`与`style.css`控制交互和样式；GitHub Pages从`main`分支根目录发布。

本机完整工作区另有生成入口，在该工作区根目录执行：

```sh
python -X utf8 work/build_twelve_day.py
```

`work/`中的原始报价、截图、校验与生成脚本位于公开仓库之外，单独克隆本仓库不会取得这些文件。2026-10-27起，网站文件由私有工作区生成并检查后自动同步到本仓库；不要直接在本仓库修改，下次同步会覆盖。后续更新按工作区根目录的说明操作：按同一日期、人数和费用范围重核，再检查生成结果。

地图使用[Leaflet 1.9.4](https://leafletjs.com/)和[OpenStreetMap](https://www.openstreetmap.org/copyright)，Leaflet许可见`assets/LEAFLET-LICENSE`。没有瓦片批量下载或离线缓存；远程照片或底图受网络影响时，文字行程及导航链接仍可使用。
